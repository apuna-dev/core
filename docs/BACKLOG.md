# Backlog

All ideas, bugs, and feature requests land here before they move into a sprint. The CEO ranks items; the Leader decomposes them; AD facilitates the sprint ceremony.

## Format

```
### [TYPE] Short title
**Priority:** TBD / High / Medium / Low  
**Size:** 📕 epic · 📗 novel · 📘 novella · 📄 short story  
**Status:** captured | ranked | in-sprint | done | deferred  

Description of the item — what needs to exist that doesn't exist now.
```
